# Komek By Ticket - Laravel Implementation

A pixel-perfect replication of the "Komek By Ticket" Figma design, built using the Laravel framework.

## 🚀 Features

- **Pixel-Perfect UI:** Precise implementation of the desktop design from Figma.
- **Responsive Adaptivity:** Optimized for mobile and tablet devices.
- **Blade Components:** Modular architecture using Laravel Blade (Header, Footer, Layout, MovieCard).
- **Modern Styling:** Built with SCSS and Vite for fast, efficient asset loading.
- **Cinematic Experience:** High-quality background collage and hero sections.

## 🛠 Technology Stack

- **Backend:** Laravel 11 (PHP 8.3+)
- **Frontend:** Blade Templates, SCSS, JavaScript
- **Build Tool:** Vite
- **Assets:** SVG Logos, Remote Cinematic Imagery

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ZhaslanToishybayev/komek-by-ticket.git
   cd komek-by-ticket
   ```

2. **Install dependencies:**
   ```bash
   composer install
   npm install
   ```

3. **Setup environment:**
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. **Compile assets:**
   ```bash
   npm run build
   ```

5. **Start the server:**
   ```bash
   php artisan serve
   ```
